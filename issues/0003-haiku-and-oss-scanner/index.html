Claude Haiku 5.5, a small model for subagents

Fast, for high-volume work, with an effort setting

Anthropic released Claude Haiku 5.5 on 7 October 2026 and calls it the fastest and most capable small model it has released. It is built for quick, repeated work such as summaries, compaction, database queries and classification, and it "pairs well with Opus 5.5 and Sonnet 5.5 as a subagent on coding work". It is the first Haiku-class model with an adjustable effort setting. On OSWorld 2.1 it scores 72.4% against 15.7% for Haiku 4.5, and on Terminal-Bench 4.0 39.2% against 0.0%. Anthropic says plainly that Sonnet 5.5 and Opus 5.5 remain the better choice for complex agentic coding.

Source: Anthropic: Claude Haiku 5.5

In brief

Anthropic offers open-source projects free security scans

On 8 October 2026 Anthropic announced OSS Scanner, an opt-in service inspired by Google's OSS-Fuzz. Core maintainers of open-source projects can enrol, and their projects get periodic scans by Anthropic's most capable models free of charge. Each report contains an explanation, a proof of concept of how the bug could be exploited and, where possible, a suggested fix. The reports are written by the model and sent without human review; Anthropic expects more than 90% of them to be true positives.

Source: Anthropic: Anthropic's cyber mission

Copilot runs local commands in a sandbox

Since 7 October 2026 local sandboxing for GitHub Copilot is generally available in Copilot CLI, the GitHub Copilot app and VS Code sessions that use Agent Host, on Windows, macOS and Linux. Commands that Copilot starts get limited access to files and folders, to the internet and the local network, and to Git and GitHub CLI credentials. The sandbox can also cover local MCP servers and language servers. Organisations can require it and set rules that developers cannot weaken.

Source: GitHub Changelog: Local sandboxing for GitHub Copilot now generally available

Stacked pull requests for everyone on GitHub

On 6 October 2026 stacked pull requests became generally available on all github.com plans. A large change can be split into smaller, related pull requests that are reviewed separately and merged in order. During the preview, repositories that used stacks merged 9% more code than their peers. A whole stack goes through the merge queue as one group, and the gh stack extension of the GitHub CLI now works with Git worktrees.

Source: GitHub Changelog: Stacked pull requests are generally available

Microsoft grades agents by what they leave behind

On 3 October 2026 Microsoft presented ThinkingBox, which judges an agent by the final state of the backend and its side effects, not by what the agent says. Its benchmark has 507 business workflows that change data, each run 20 times from a clean backend. The best model, Claude Opus 5.5, solved 67.16% on a single try, and even the best models solved only 47.53% of the tasks in all 20 runs. About 79.9% of failures came from tool use. The code is under the MIT licence.

Sources: Hugging Face: ThinkingBox · GitHub: microsoft/thinkingbox

Claude helps draw the first full ultraviolet map of the sky

On 8 October 2026 Anthropic described how astrophysicist Brice Ménard, working with Claude, produced "the first complete map of the sky in UV light". NASA's GALEX telescope had imaged about two thirds of the sky; Claude's agents calibrated those data and merged them with other surveys. For the missing third, Claude learned how UV brightness relates to other wavelengths, and in hidden test regions its estimates came within about 10% of real measurements. The map is public, and every pixel is marked "measured" or "predicted".

Source: Anthropic: The missing map of the sky

EU registers a citizens' initiative for a .IA domain

On 6 October 2026 the European Commission registered the European Citizens' Initiative "Creation of a European Digital Space (.IA) for Sovereign AI Governance". It asks for an EU framework of trusted digital spaces and sandboxes for testing ethical AI, and for talks with ISO and ICANN/IANA to reserve the .IA domain for Europe. Registration only means the initiative is legally admissible. If the organisers collect one million signatures, with minimums in at least seven Member States, the Commission must respond.

Source: European Commission: European Citizens' Initiative on sovereign AI governance

One thing to try

Compare a question and an answer with EmbeddingGemma 2

Google released EmbeddingGemma 2 on 6 October 2026, an open embedding model under Apache 2.0 that puts text, images, audio, video and code into one shared space; for text alone it needs as little as 270 million parameters. Install sentence-transformers, load SentenceTransformer("google/embeddinggemma-2"), encode a question with prompt_name="SearchQuery" and a passage with prompt_name="Document", then print model.similarity(...) of the two, as the model card shows. Then swap in your own question and passages and see which one the model puts closest.

Sources: Google: EmbeddingGemma 2 · Hugging Face: google/embeddinggemma-2
