Skribly AI News: Codex, OpenCode, Claude Code and GitHub

OpenAI Codex 0.169.0

The latest release brings an opt-in terminal workspace supporting multiple side-chat tabs. Users can switch between tabs using the keyboard or mouse and reopen saved local side chats after restarting Codex. It also adds a feature to search older tasks from the agent command center by name or prompt.

Source: OpenAI Codex releases: 0.169.0

In brief

OpenCode v2.3.0

Version v2.3.0 highlights background subagents by default, allowing subagents to return immediately and continue running in the background. Developers can keep working in the parent session while multiple subagents run concurrently. Transcripts are also quieter by default.

Source: OpenCode releases: v2.3.0

Claude Code v2.1.323

Claude Code adds Code Mode as an experimental opt-in feature where Claude writes JavaScript to call its tools. This version also introduces support for the engines parameter in plugin.json.

Source: Claude Code releases: v2.1.323

Manage AI Scan via REST API

GitHub now lets you turn GitHub code scanning’s AI Scan for repositories on or off using the REST API. This feature is available at both organization and repository levels during public preview.

Source: GitHub Changelog: Manage AI Scan for repositories using the REST API

Secret scanning detects Cloudflare tokens

Secret scanning now automatically detects Cloudflare service tokens in your repositories. The update adds a new detector for cloudflare_access_service_token secrets.

Source: GitHub Changelog: Secret scanning detects Cloudflare service tokens
