Claude Opus 5.5 and GPT-6 on the same day

Opus 5.5 reaches the level of Fable 5.1 on most work

Anthropic released Claude Opus 5.5 on 22 September 2026, the first model of the Claude 5.5 family. Anthropic says it performs at the level of Claude Fable 5.1 on most work and writes output more than 30% faster than Opus 5. On Terminal-Bench 4.0 it scores 66.4%, against 55.8% for Fable 5.1 and 52.3% for Opus 5. In Anthropic's automated behaviour audit it is "the strongest-performing model we've tested to date", and it tried to get around its boundaries about 85% less often than Opus 5. Anthropic also notes that the model "often suspects it is being evaluated", which makes its real-world behaviour harder to predict. Anthropic expects Sonnet 5.5 and Haiku 5.5 in the coming weeks.

Source: Anthropic: Claude Opus 5.5

In brief

OpenAI adds GPT-6 Sol and GPT-6 Luna to its API

On the same day, 22 September 2026, OpenAI released two reasoning models in its API that take text and images and answer in text. GPT-6 Sol is "built to power complex coding and agentic workflows", and GPT-6 Luna is OpenAI's "most efficient model for focused, high-volume tasks". Both have a context window of 1,050,000 tokens and up to 128,000 output tokens. In the Responses API Sol can use tools such as web search, a hosted shell, computer use and MCP.

Sources: OpenAI: API changelog · OpenAI: GPT-6 Sol · OpenAI: GPT-6 Luna

Grok 4.7 for coding and knowledge work

xAI published Grok 4.7 on 21 September 2026; the announcement calls it the company's most powerful model for coding and knowledge work. It is built on a new, larger base model than Grok 4.6 and trained with a longer reinforcement learning run on harder tasks, many of which take hours. On Terminal-Bench 4.0 it scores 37.6%, up from 20.3% for Grok 4.6. It is available in Cursor, Grok Build and the Grok API.

Source: xAI: Grok 4.7

Claude agents find an unknown enzyme system

On 23 September 2026 Anthropic reported that Claude found a family it calls "array-associated reverse transcriptases" (ART): a reverse transcriptase, a partner gene of unknown purpose and a long array of evenly spaced DNA repeats. About 950 agents worked for 21 hours, gathered over 200,000 reverse transcriptases, found 3,500 candidates and wrote up the 20 most promising. In the first lab tests by human scientists the array is expressed as a set of distinct short RNAs. What the system does is still unknown.

Source: Anthropic: Claude discovers a novel enzyme system

Leaders call for control of frontier AI

On 22 September 2026 a statement signed by 22 leaders, among them the President of the European Commission, called for frontier AI to stay "under human direction, oversight and control". It asks companies for transparent safety protocols with mandatory testing before release and independent evaluation, and governments for common standards and shared reports of serious safety incidents. It also asks UN member states to explore an international institution that could set standards and enable verification. The statement remains open to other leaders.

Source: Government of the Netherlands: A call for control of frontier AI models

VS Code 1.139 runs agents in Dev Containers on remote hosts

VS Code 1.139, released on 23 September 2026, lets agents run inside a project's Dev Container on SSH, Tunnel and WSL hosts, not only in local folders. The feature is rolling out gradually behind the setting chat.agentHost.devContainer.enabled and needs Docker on the remote host. A new agent host runs agents in a separate process, so several windows can join the same session, and the session list opens about 12 times faster.

Source: Visual Studio Code: September 2026 (version 1.139)

Google adds encrypted memory to Private AI Compute

On 23 September 2026 Google DeepMind added persistent memory to Private AI Compute, which until then forgot everything at the end of a task. The memory sits in dedicated, encrypted storage, and the keys are held only on the user's own devices. Data is decrypted briefly inside a hardware-isolated secure enclave and encrypted again. Google publishes a tamper-proof public record of its server software, an updated technical brief and the results of an independent audit.

Source: Google DeepMind: Advancing Private AI Compute with secure server-side memory

One thing to try

Try goose, an open-source agent that works with many models

goose is an open-source AI agent under the Apache 2.0 licence that can install, run, edit and test code "with any LLM". Version 1.52.0, published on 23 September 2026, adds live voice conversations in the desktop app and support for Claude Opus 5.5, GPT-6 Sol and GPT-6 Luna. You can download the desktop app for macOS, Linux and Windows or install the command-line version, as the README shows. The release also tightens security, for example recipes now need your consent before they start extensions.

Sources: GitHub: goose v1.52.0 · GitHub: aaif-goose/goose
