Claude Duet works on its own, and asks before it acts

An agent that brings you what needs attention

On 21 October 2026 Anthropic opened a research preview of Claude Duet, a new app in which Claude works as a proactive agent. It points out what needs your attention, does the tasks you give it and keeps working while you are away. Duet is built around Claude Opus 5.5 and runs as its own app on iOS and Android and on claude.ai, separate from the main Claude app. It reads and drafts on its own, but before it sends a message, makes a payment, signs a document or deletes anything, it shows exactly what it is about to do and waits for your approval; some actions, such as moving money between accounts, stay blocked even then. Access starts with a waitlist for subscribers in the US.

Source: Claude: Introducing Claude Duet

In brief

A package firewall for coding agents and CI

On 20 October 2026 GitHub put a package firewall in public preview. It sits between your machines or internal registries and the public package registries and checks every package request against a policy: a waiting period for new versions, the GitHub Advisory Database for malware and vulnerabilities, and supply-chain checks. GitHub aims it at coding agents and CI runners, which install dependencies without a person looking at each one. For now it supports npm and is for GitHub Enterprise Cloud.

Source: GitHub Changelog: GitHub package firewall in public preview

DeepSeek updates V4.1 Flash

DeepSeek published DeepSeek-V4.1-Flash-1017 on Hugging Face on 17 October 2026. The model card calls it a minor update with large gains in reasoning, coding, agentic tasks and visual benchmarks, and says it finishes tasks faster with less generated text. The recommended context is one million tokens. Both the code and the weights are under the MIT licence.

Source: Hugging Face: deepseek-ai/DeepSeek-V4.1-Flash-1017

Voxtral 3 listens and speaks, Polish included

Mistral released Voxtral 3 on 20 October 2026: speech-to-text in batch and in real time, with who-spoke-when, a text-to-speech model with voice cloning, and an SDK for voice agents. Transcription covers 50 languages and speech more than 35, and Polish is on both lists. It is available through Mistral's API and the Studio playgrounds, or deployed on your own servers.

Source: Mistral AI: Voxtral 3

Claude Security now watches code all the time

On 21 October 2026 Anthropic said Claude Security, its vulnerability scanner in public beta for Claude Enterprise, now scans repositories continuously instead of waiting for a manual scan. It marks a finding as fixed when the fix lands and reopens it if the problem comes back, builds an editable threat model of the project and explains how an attacker could reach the vulnerable code. It also gains an API, webhooks and an MCP connector for Claude.ai and Claude Code.

Source: Claude: Claude Security now scans continuously and tracks fixes

A map of the world's forest types

On 22 October 2026 Google DeepMind and Google Research, with the World Resources Institute and IIASA, published ForTy, a map that sorts every 10 by 10 metre patch of land into six forest and land-use types. It was trained on about 1.7 million labelled locations and named the right forest type 90% of the time in checks at more than 9,000 sites. An early time series for 2017 to 2025 shows where natural forest turned into plantations or farms. The data is free on Google Earth Engine under an open licence.

Source: Google DeepMind: Beyond tree cover, mapping the world's forest types

Anthropic invites life scientists as guest investigators

On 22 October 2026 Anthropic opened a call for guest investigators in the life sciences: research groups at universities, nonprofits and government labs work for 8 to 12 weeks with Anthropic researchers on a project they choose. Anthropic runs its models at no cost to them, the results are published and the data and code are released as open source. Applications were open for about 14 days.

Source: Anthropic: Open call for guest investigators in the life sciences

One thing to try

Sign in to GitHub CLI with tokens that expire

Since 21 October 2026 GitHub CLI can keep you signed in with a short-lived access token that renews itself, so a leaked token stops working within hours. Update gh to version 2.103.0 or later and run gh auth login --expiring, or turn it on for every sign-in with gh config set expiring_credentials enabled. gh auth status shows when the current token expires. Scripts should ask gh auth token for a token each time instead of saving one.

Source: GitHub Changelog: GitHub CLI opt in to expiring, auto-refreshing OAuth tokens
