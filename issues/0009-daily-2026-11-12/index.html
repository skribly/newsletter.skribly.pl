Codex Updates and New Developer Tools

Codex 0.167.2 Release

Codex now sends tool updates incrementally by default when running on Google Cloud Vertex AI. Developers can opt out of this behavior by setting incremental_tools_legacy_gcp to false under features in config.toml.

Source: OpenAI Codex releases: 0.167.2

In brief

Issue Types and Fields for Personal Accounts

Issue types and issue fields are now generally available on repositories owned by personal accounts. This update brings standardized planning capabilities to individual developers and open source maintainers.

Source: GitHub Changelog: Issue types and fields are available for personal accounts

Gemini Decisions API Released

Google introduced the Gemini Decisions API, which is powered by the Gemini Decision model. The API is designed to deliver fast and calibrated multimodal decisions.

Source: Google AI Blog: Gemini Decisions API: Fast, calibrated multimodal decisions

Tabletop Group Collaboration Experiment

Tabletop is a new Google Labs experiment focused on customizable and collaborative spaces for groups. Teams can use it to build interactive itineraries, polls, and brackets together.

Source: Google AI Blog: Try Tabletop: Customizable, collaborative spaces for groups to plan, play and do more togethe…

AlphaGenome 2 Decodes DNA

AlphaGenome 2 aims to decipher how cells read DNA in order to better understand disease. The model predicts how DNA sequences and their variations impact specific human cell types and diseases.

Source: Google DeepMind Blog: AlphaGenome 2: Deciphering how cells read DNA to better understand disease
