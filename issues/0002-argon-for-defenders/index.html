Gemini 4 Argon goes to cyber defenders first

A frontier model for long work, released to defenders before everyone else

On 30 September 2026 Google introduced Gemini 4 Argon, its frontier model for real-world coding, enterprise knowledge work and cyber defence. It first went to a set of trusted cyber defenders through Google's Fairwind Program; Google plans a wider release later, without a date. The output limit grows to one million tokens, up from 64,000. Google reports 77.9% on DeepSWE v1.1, a new state of the art, and a shared first place on CWE-bench v1 with 68%. In one example Google's agents replaced 32,000 lines of SIMD code in its open-source video decoder libgav1 with safe Rust, and the result runs 2.7 times faster than the existing Rust port with identical output.

Source: Google: Gemini 4 Argon

In brief

Claude Sonnet 5.5: faster, aimed at everyday work

Anthropic released Claude Sonnet 5.5 on 28 September 2026. It writes output more than 30% faster than Sonnet 5 and is strongest at well-scoped everyday tasks, fixing bugs and polished documents, slides and spreadsheets. Anthropic says plainly that it "doesn't advance the frontier" of its models; on Terminal-Bench 4.0 it scores 70.6% against 10.3% for Sonnet 5. It is the first Sonnet launched with cyber safeguards: higher-risk security requests fall back to Sonnet 5, while routine bug fixing is not affected.

Source: Anthropic: Claude Sonnet 5.5

OpenAI adds GPT-6.1 Sol to its API

On 29 September 2026 OpenAI released GPT-6.1 Sol in its API for complex coding and professional work. The model page describes it as "near-Astra performance for complex work", with a context window of 1,050,000 tokens and up to 128,000 output tokens. It also supports Multi-agent in beta, so the model can hand parts of a task to subagents. The same day OpenAI added computer use to its Agents API: agents can finish tasks in a browser hosted by OpenAI.

Sources: OpenAI: developer changelog · OpenAI: GPT-6.1 Sol model page

Copilot learns to use desktop apps

Since 1 October 2026 GitHub Copilot can work in desktop apps for you, as a public preview in Copilot CLI and the GitHub Copilot app on macOS and Windows. It reads what an app shows, clicks, types, scrolls and moves between apps, so it can also handle software that has no API, CLI or MCP integration. Copilot asks for approval before it controls an app, and organisations can switch the feature off. In the CLI you turn it on with /computer on.

Source: GitHub Changelog: GitHub Copilot can now interact with desktop apps

H Company opens the weights of its Holo4 agent models

On 28 September 2026 H Company published Holo4, a series of agent models that work with software through graphical interfaces, code, MCP and APIs. There are two sizes, Holo4-27B and Holo4-35B-A3B, with weights on Hugging Face. On OSWorld 2.0 the 27B model scores 61.7%, against 81.8% for Claude Opus 5.5. The licences differ: the model card of Holo4-35B-A3B says Apache 2.0, that of Holo4-27B a non-commercial CC BY-NC 4.0. H Company also publishes every trajectory behind its benchmark scores.

Sources: Hugging Face: Holo4 · Hugging Face: Holo4-35B-A3B · Hugging Face: Holo4-27B

A watermark for proteins designed with AI

On 30 September 2026 Google DeepMind introduced SynthID Bio, watermarks that sit in the biological code itself. For AlphaFold 3 the team fine-tuned a small part of the model, so its predicted structures carry the watermark whoever runs it. In the lab, watermarked protein binders against three targets matched unwatermarked ones in hit rate and binding strength. DeepMind will publish a methods paper, the code, the lab data and the weights for researchers, and says resistance to deliberate tampering is still a key challenge.

Source: Google DeepMind: Introducing SynthID Bio

EU asks about copyright and AI

On 29 September 2026 the European Commission opened a targeted consultation on how technology affects copyright. The first of its four areas is "the use of copyright-protected content in artificial intelligence"; the others are online piracy of live events, the pay of music performers and producers, and the copyright of scientific research. Developers of generative AI were among those invited to answer. The deadline, first 3 November, was extended to 10 November 2026.

Source: European Commission: feedback on the effect of technology on copyright

One thing to try

Run an RL environment from the Hugging Face Hub

Since 28 September 2026 reinforcement learning environments live on the Hugging Face Hub as ordinary dataset repositories, with an "RL Environments" filter and no sign-up. You can try one with Harbor, an open-source framework, without an API key: install it with uv tool install --python 3.13 'harbor==0.21.0' and run one task of Terminal-Bench 2.1 with --agent oracle --env docker, as shown in the post. The oracle agent runs the reference solution and calls no model, so you need only Docker. harbor view then shows the reward, the verifier output and the logs.

Source: Hugging Face: RL environments on the Hub
