Claude in the drug lab

Claude helps drug developers from design to paperwork

On 27 October 2026 Anthropic reported early results from partnerships with six drug developers and from its own drug programme. At Generate Biomedicines, scientists used Claude Code to propose a genetic component for CAR T-cell therapy that is about 70% shorter than the standard one; in lab tests the immune cells made roughly ten times as many receptors. At BigHat Biosciences, Claude proposed changes to two antibody fragments, and the best versions bound more than ten times more tightly. At Enveda, Claude checked 1,061 pages of manufacturing documentation, caught all 11 issues that human reviewers had found and seven more, and cut human review time by 89%. Anthropic stresses that the work is at an early stage and mostly preclinical, which means not yet tested in people.

Source: Anthropic: Early progress on accelerating drug development with Claude

In brief

GPT-6.1 Terra, a fast model for computer use

OpenAI released GPT-6.1 Terra on 26 October 2026 in the Responses and Chat Completions APIs. OpenAI calls it "a fast, efficient model for visual reasoning, precise computer use, and clear, natural writing". It reads text and images, has a context of about one million tokens and can use tools such as computer use and MCP. The same day it arrived in GitHub Copilot, which aims it at everyday agentic coding and work in the terminal.

Sources: OpenAI: API changelog · OpenAI: GPT-6.1 Terra · GitHub Changelog: GPT-6.1 Terra in GitHub Copilot

Kimi K3.1 Pro, with its cyber skills held back

Moonshot AI introduced Kimi K3.1 Pro in a post dated 24 October 2026 on the Kimi blog, calling it its most capable 3T-class open-weight model, with a context of one million tokens. A Highspeed variant runs two to three times faster. The model is available on Kimi.com, in Kimi Work, Kimi Code and the Kimi API, and Moonshot promised the full weights by 4 November. It also removed cyber-related data from training, because it aims not to release open weights that would push the frontier of cyber capability.

Source: Kimi: Kimi K3.1 Pro

Genie 4 builds worlds with sound

On 27 October 2026 Google DeepMind announced Genie 4, a world model that generates interactive environments in real time. New are native audio, such as music, ambient sound and character dialogue, and changing a scene in plain language, for example the weather or the camera. It is a research preview for trusted testers, and DeepMind says details and object permanence can still drift over time. Every generated video and sound carries a SynthID watermark.

Source: Google DeepMind: Genie 4, a new generation of world simulation

Agent workflows in GitHub Actions are generally available

GitHub Agentic Workflows, an open-source project from GitHub Next, became generally available on 28 October 2026. You describe an automation, such as issue triage or the analysis of a failed build, in plain language in a Markdown file, and the tool compiles it into ordinary Actions YAML. Agents run with read-only permissions by default, in a sandbox behind a firewall, and a separate threat detection job checks proposed changes before they are applied. The default engine, the Copilot CLI, needs a Copilot licence.

Source: GitHub Changelog: GitHub Agentic Workflows generally available

Replica makes prototypes from your own design system

Also on 28 October GitHub Design released Replica, an open-source tool for prototypes made with AI, under the MIT licence. Unlike generic tools, it builds prototypes from the team's existing components, patterns and documentation. You describe the idea in the GitHub Copilot app and refine the prototype next to the conversation; an optional, self-hosted Replica Hub lets teammates look and comment.

Sources: GitHub Changelog: Introducing Replica · GitHub: github/replica

Lockfiles for GitHub Actions

Workflow lockfiles for GitHub Actions became generally available on 28 October 2026. Your workflows keep readable tags, while .github/workflows/actions.lock, made with the gh actions-lock extension, records the exact commits of each action and its dependencies, and those commits run even if a tag moves. GitHub notes that a lockfile protects against unexpected changes but does not tell you whether a dependency is safe.

Sources: GitHub Changelog: GitHub Actions workflow lockfiles are generally available · GitHub: github/gh-actions-lock

Skribly Agent 1.0.27, dated 29 October in our public changelog, makes Skribly Tracker the default tracker. The changelog on docs.skribly.pl lists what changes in Skribly Agent, Skribly Tracker and agent-skills, in plain words and newest first.

Source: docs.skribly.pl: changelog

One thing to try

Run LFM3 on your own computer

LFM3-1.7B from Liquid AI, released on 27 October 2026, is a small open-weight model with 1.73 billion parameters and a context of 256K tokens, and Polish is one of its 16 languages. With Docker Model Runner one command starts it: docker model run hf.co/LiquidAI/LFM3-1.7B. For llama.cpp, Ollama or LM Studio there is a GGUF build, and for Apple Silicon an MLX build. It comes under the LFM Open License v1.0, so read the licence before you put it in a product.

Sources: Liquid AI: Introducing LFM3 · Hugging Face: LiquidAI/LFM3-1.7B
