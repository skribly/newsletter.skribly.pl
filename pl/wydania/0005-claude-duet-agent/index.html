Agent, który podsuwa ci to, co wymaga uwagi

21 października 2026 Anthropic otworzył podgląd badawczy Claude Duet, nowej aplikacji, w której Claude działa jako agent z własną inicjatywą. Wskazuje, co wymaga twojej uwagi, wykonuje zlecone zadania i pracuje dalej, gdy cię nie ma. Duet jest zbudowany wokół Claude Opus 5.5 i działa jako osobna aplikacja na iOS i Androida oraz na claude.ai, niezależnie od głównej aplikacji Claude. Sam czyta i przygotowuje szkice, ale zanim wyśle wiadomość, zapłaci, podpisze dokument albo coś usunie, pokazuje dokładnie, co zamierza zrobić, i czeka na twoją zgodę; niektóre działania, na przykład przelewy między kontami, są zablokowane nawet wtedy. Dostęp zaczyna się od listy oczekujących dla subskrybentów w USA.

Źródło: Claude: Introducing Claude Duet

W skrócie

Zapora pakietów dla agentów i CI

20 października 2026 GitHub udostępnił zaporę pakietów w publicznym podglądzie. Stoi między twoimi maszynami lub wewnętrznymi rejestrami a publicznymi rejestrami pakietów i sprawdza każde żądanie według zasad: okresu karencji dla nowych wersji, bazy GitHub Advisory Database pod kątem złośliwego kodu i podatności oraz kontroli łańcucha dostaw. GitHub kieruje ją do agentów programujących i maszyn CI, które instalują zależności bez człowieka zaglądającego w każdą z nich. Na razie obsługuje npm i jest dla GitHub Enterprise Cloud.

Źródło: GitHub Changelog: GitHub package firewall in public preview

DeepSeek odświeża V4.1 Flash

DeepSeek opublikował 17 października 2026 na Hugging Face model DeepSeek-V4.1-Flash-1017. Karta modelu nazywa go drobną aktualizacją z dużą poprawą w rozumowaniu, programowaniu, zadaniach agentowych i testach wizualnych. Model ma też kończyć zadania szybciej i generować mniej tekstu. Zalecany kontekst to milion tokenów, a kod i wagi są na licencji MIT.

Źródło: Hugging Face: deepseek-ai/DeepSeek-V4.1-Flash-1017

Voxtral 3 słucha i mówi, także po polsku

Mistral wydał 20 października 2026 Voxtral 3: zamianę mowy na tekst w trybie wsadowym i na żywo, z rozpoznawaniem, kto mówi, model zamiany tekstu na mowę z klonowaniem głosu i SDK do agentów głosowych. Transkrypcja obejmuje 50 języków, a synteza mowy ponad 35, i polski jest na obu listach. Voxtral 3 działa przez API Mistrala i w Studio albo na własnych serwerach.

Źródło: Mistral AI: Voxtral 3

Claude Security pilnuje kodu bez przerwy

21 października 2026 Anthropic ogłosił, że Claude Security, jego skaner podatności w publicznej becie dla Claude Enterprise, skanuje repozytoria w sposób ciągły, zamiast czekać na ręczne uruchomienie. Oznacza problem jako naprawiony, gdy poprawka trafi do kodu, i otwiera go ponownie, jeśli problem wróci. Buduje też edytowalny model zagrożeń projektu i wyjaśnia, jak atakujący mógłby dotrzeć do podatnego kodu. Doszły API, webhooki i konektor MCP dla Claude.ai i Claude Code.

Źródło: Claude: Claude Security now scans continuously and tracks fixes

Mapa rodzajów lasów na świecie

22 października 2026 Google DeepMind i Google Research razem z World Resources Institute i IIASA opublikowali ForTy, mapę, która przypisuje każdy kwadrat ziemi 10 na 10 metrów do jednego z sześciu rodzajów lasu i użytkowania terenu. Model uczył się na około 1,7 miliona opisanych miejsc i w sprawdzeniu na ponad 9 tysiącach miejsc trafnie rozpoznał rodzaj lasu w 90% przypadków. Wstępny szereg czasowy na lata 2017–2025 pokazuje, gdzie naturalny las zamienił się w plantacje lub pola. Dane są bezpłatnie dostępne w Google Earth Engine na otwartej licencji.

Źródło: Google DeepMind: Beyond tree cover, mapping the world's forest types

Anthropic zaprasza badaczy nauk o życiu

22 października 2026 Anthropic ogłosił nabór gości-badaczy z nauk o życiu: zespoły z uczelni, organizacji non-profit i laboratoriów państwowych pracują przez 8 do 12 tygodni z badaczami Anthropic nad wybranym przez siebie projektem. Anthropic uruchamia dla nich swoje modele bez kosztów, wyniki są publikowane, a dane i kod udostępniane jako open source. Zgłoszenia przyjmowano przez około 14 dni.

Źródło: Anthropic: Open call for guest investigators in the life sciences

Do wypróbowania

Loguj się do GitHub CLI tokenami, które wygasają

Od 21 października 2026 GitHub CLI może trzymać cię zalogowanym na krótko żyjącym tokenie, który sam się odnawia, więc wykradziony token przestaje działać w ciągu kilku godzin. Zaktualizuj gh do wersji 2.103.0 lub nowszej i wpisz gh auth login --expiring albo włącz to dla każdego logowania poleceniem gh config set expiring_credentials enabled. gh auth status pokaże, kiedy wygasa bieżący token. Skrypty powinny za każdym razem pobierać token przez gh auth token, zamiast go zapisywać.

Źródło: GitHub Changelog: GitHub CLI opt in to expiring, auto-refreshing OAuth tokens
