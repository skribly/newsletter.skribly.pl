Claude Haiku 5.5, mały model dla subagentów

Szybki, do pracy w dużej skali, z regulacją wysiłku

Anthropic wydał 7 października 2026 Claude Haiku 5.5 i nazywa go najszybszym i najzdolniejszym małym modelem, jaki dotąd udostępnił. Jest zbudowany do szybkiej, powtarzalnej pracy, takiej jak streszczenia, kompaktowanie kontekstu, zapytania do baz danych i klasyfikacja, i dobrze sprawdza się jako subagent przy Opusie 5.5 i Sonnecie 5.5 w pracy nad kodem. To pierwszy model klasy Haiku z regulowanym poziomem wysiłku. W OSWorld 2.1 ma 72,4% wobec 15,7% dla Haiku 4.5, a w Terminal-Bench 4.0 39,2% wobec 0,0%. Anthropic wprost pisze, że do złożonego programowania z agentami lepszym wyborem pozostają Sonnet 5.5 i Opus 5.5.

Źródło: Anthropic: Claude Haiku 5.5

Anthropic oferuje projektom open source darmowe skany bezpieczeństwa

8 października 2026 Anthropic ogłosił OSS Scanner, dobrowolną usługę wzorowaną na OSS-Fuzz od Google. Mogą się zapisać główni opiekunowie projektów open source, a ich projekty będą bezpłatnie i regularnie skanowane przez najmocniejsze modele Anthropic. Każdy raport zawiera wyjaśnienie, dowód koncepcji pokazujący, jak można wykorzystać błąd, i tam, gdzie się da, propozycję poprawki. Raporty pisze model i trafiają do opiekunów bez sprawdzenia przez człowieka; Anthropic spodziewa się, że ponad 90% z nich wskaże prawdziwe błędy.

Źródło: Anthropic: Anthropic's cyber mission

Copilot uruchamia lokalne polecenia w piaskownicy

Od 7 października 2026 lokalna piaskownica dla GitHub Copilot jest ogólnie dostępna w Copilot CLI, aplikacji GitHub Copilot i sesjach VS Code korzystających z Agent Host, na Windows, macOS i Linuksie. Polecenia uruchamiane przez Copilota mają ograniczony dostęp do plików i folderów, do internetu i sieci lokalnej oraz do danych logowania Git i GitHub CLI. Piaskownica może też objąć lokalne serwery MCP i serwery języków. Organizacje mogą ją wymusić i ustawić zasady, których programiści nie osłabią.

Źródło: GitHub Changelog: Local sandboxing for GitHub Copilot now generally available

Piętrowe pull requesty dla wszystkich na GitHubie

6 października 2026 piętrowe pull requesty (stacked pull requests) stały się ogólnie dostępne we wszystkich planach github.com. Dużą zmianę można podzielić na mniejsze, powiązane pull requesty, które przegląda się osobno i scala po kolei. W wersji próbnej repozytoria używające takich stosów scalały o 9% więcej kodu niż podobne repozytoria. Cały stos przechodzi przez kolejkę scalania jako jedna grupa, a rozszerzenie gh stack do GitHub CLI działa teraz z git worktree.

Źródło: GitHub Changelog: Stacked pull requests are generally available

Microsoft ocenia agentów po tym, co po sobie zostawiają

3 października 2026 Microsoft przedstawił ThinkingBox, który ocenia agenta po końcowym stanie systemu i skutkach jego działań, a nie po tym, co agent mówi. Jego test ma 507 firmowych procesów zmieniających dane, a każdy jest uruchamiany 20 razy od czystego stanu. Najlepszy model, Claude Opus 5.5, rozwiązał 67,16% za jednym podejściem, a nawet najlepsze modele rozwiązały we wszystkich 20 próbach tylko 47,53% zadań. Około 79,9% porażek wynikało z użycia narzędzi. Kod jest na licencji MIT.

Źródła: Hugging Face: ThinkingBox · GitHub: microsoft/thinkingbox

Claude pomaga narysować pierwszą pełną mapę nieba w ultrafiolecie

8 października 2026 Anthropic opisał, jak astrofizyk Brice Ménard razem z Claude stworzył pierwszą kompletną mapę nieba w świetle UV. Teleskop GALEX z NASA sfotografował około dwóch trzecich nieba; agenci Claude skalibrowali te dane i połączyli je z innymi przeglądami. Dla brakującej jednej trzeciej Claude nauczył się, jak jasność w UV wiąże się z innymi długościami fal, a w ukrytych obszarach testowych jego szacunki różniły się od pomiarów o około 10%. Mapa jest publiczna, a każdy piksel ma oznaczenie „zmierzony” albo „przewidziany”.

Źródło: Anthropic: The missing map of the sky

UE rejestruje inicjatywę obywatelską w sprawie domeny .IA

6 października 2026 Komisja Europejska zarejestrowała europejską inicjatywę obywatelską „Tworzenie europejskiej przestrzeni cyfrowej na rzecz suwerennego zarządzania sztuczną inteligencją”. Jej autorzy chcą unijnych ram dla zaufanych przestrzeni cyfrowych i piaskownic do testowania etycznej AI oraz rozmów z ISO i ICANN/IANA o zarezerwowaniu domeny .IA dla Europy. Rejestracja oznacza tylko, że inicjatywa jest dopuszczalna prawnie. Jeśli organizatorzy zbiorą milion podpisów, z minimalną liczbą w co najmniej siedmiu państwach członkowskich, Komisja musi odpowiedzieć.

Źródło: Komisja Europejska: europejska inicjatywa obywatelska w sprawie AI

Porównaj pytanie z odpowiedzią w EmbeddingGemma 2

Google wydał 6 października 2026 EmbeddingGemma 2, otwarty model embeddingów na licencji Apache 2.0, który umieszcza tekst, obrazy, dźwięk, wideo i kod we wspólnej przestrzeni; do samego tekstu wystarcza mu 270 milionów parametrów. Zainstaluj sentence-transformers, wczytaj SentenceTransformer("google/embeddinggemma-2"), zakoduj pytanie z prompt_name="SearchQuery" i fragment tekstu z prompt_name="Document", a potem wypisz model.similarity(...) dla obu, tak jak w karcie modelu. Następnie podstaw własne pytanie i fragmenty i zobacz, który model uzna za najbliższy.

Źródła: Google: EmbeddingGemma 2 · Hugging Face: google/embeddinggemma-2
