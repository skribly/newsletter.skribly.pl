Skribly AI News: Codex, OpenCode, Claude Code i GitHub

OpenAI Codex 0.169.0

Najnowsze wydanie wprowadza opcjonalną przestrzeń roboczą terminala obsługującą wiele kart czatów bocznych. Użytkownicy mogą przełączać się między nimi za pomocą klawiatury lub myszy oraz ponowne otwierać zapisane lokalne czaty po restarcie programu. Dodano także wyszukiwanie starszych zadań w centrum dowodzenia agenta.

Źródło: OpenAI Codex releases: 0.169.0

W skrócie

OpenCode v2.3.0

Wersja v2.3.0 wyróżnia podagentów działających domyślnie w tle, co pozwala im natychmiast wracać do działania i kontynuować pracę, gdy staną się bezczynni. Programiści mogą pracować w sesji nadrzędnej, podczas gdy wielu podagentów działa współbieżnie. Zapisy rozmów stały się też domyślnie spokojniejsze.

Źródło: OpenCode releases: v2.3.0

Claude Code v2.1.323

Claude Code dodaje tryb kodu jako eksperymentalną funkcję opcjonalną, w której Claude pisze kod w języku JavaScript do wywoływania swoich narzędzi. Wersja ta wprowadza również obsługę parametrów silników w pliku plugin.json.

Źródło: Claude Code releases: v2.1.323

Zarządzanie skanowaniem AI przez REST API

GitHub pozwala teraz włączać i wyłączać funkcję AI Scan skanowania kodu dla repozytoriów za pomocą REST API. Ta funkcja jest dostępna na poziomie organizacji oraz repozytoriów w ramach publicznej wersji zapoznawczej.

Źródło: GitHub Changelog: Manage AI Scan for repositories using the REST API

Skanowanie sekretów wykrywa tokeny Cloudflare

Skanowanie sekretów automatycznie wykrywa teraz tokeny usług Cloudflare w repozytoriach. Aktualizacja dodaje nowy detektor dla sekretów typu cloudflare_access_service_token.

Źródło: GitHub Changelog: Secret scanning detects Cloudflare service tokens
